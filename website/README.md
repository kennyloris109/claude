# Ocean Marine Services website

A single-file static website: `index.html` holds all the HTML, CSS and JavaScript. Fonts load from Google Fonts.

Open `index.html` in a browser to view it. To put it online, upload the `website` folder to any static host (GitHub Pages, Netlify, Cloudflare Pages).

The quotation form checks the IMO number's check digit, then opens the visitor's email app with the request addressed to oceanmarineservices.pk@gmail.com. The site has no server, so nothing is stored.
